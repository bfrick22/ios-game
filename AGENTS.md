# EMP Escape: agent guide

Rules for any AI agent (Claude Code, Codex, Cursor, Copilot, etc.) working in this Unity project.
Read this first, then load the matching skill in `.claude/skills/` before starting a task.

## The game
Single-player, chapter-based, dialogue-driven survival game for iOS in the style of Telltale Games.
Modern United States after an EMP/AI attack. Serious, grounded, hopeful.
Full design rules: `.claude/skills/emp-escape-design/SKILL.md`.

## Stack
| Piece | Choice |
|---|---|
| Engine | Unity 6.6 (6000.6.8f1), Universal 3D (URP) template |
| Input | Input System package only (`UnityEngine.InputSystem`); no legacy `Input.*` |
| Dialogue | Ink via `com.inkle.ink-unity-integration` (git URL, `#upm` branch) |
| Navigation | AI Navigation package (`NavMeshSurface`, `NavMeshAgent`) |
| Art | Kenney CC0 kits (Car Kit, City Kit, Animated Characters) rigged and animated via Mixamo; grey placeholders when missing |
| Target | iOS, landscape, iPhone first |
| Not bought | Adventure Creator ($80). Don't write code that depends on it |

## Layout
```
Assets/EMPEscape/
  Scripts/   runtime code, namespace EMPEscape, one system per file
  Editor/    editor tools, namespace EMPEscape.EditorTools
  Ink/       story files: chapter1_slice.ink, sandbox.ink
  Scenes/    Slice.unity, Sandbox.unity + baked NavMeshes (generated by the builders)
  Art/       Characters/ Animations/ Vehicles/ City/ Weapons/ (owner-supplied models), SliceArtSet.asset, EMPCharacter.controller
  Materials/ placeholder materials (generated)
  Resources/ Audio/*.wav (played by name), FieldGuide/fieldguide.json, Phone/contacts.json
ios-game/    Xcode project Unity builds into. Generated; never edit by hand
```

## Hard rules
- Commit `.claude/`, `AGENTS.md` and `CLAUDE.md` with code changes. Untracked skills were lost once in a folder reshuffle.
- Don't touch `Library/`, `Temp/`, `Logs/`, `UserSettings/`, `*.csproj`, `*.slnx`, `ios-game/`, or `*_BackUpThisFolder_*`. Unity or Xcode regenerates them.
- Never hand-write `.meta` files. Unity creates them. When moving or renaming an asset outside Unity, move its `.meta` with it.
- Scenes are generated: `Slice.unity` by `Editor/SliceSceneBuilder.cs`, `Sandbox.unity` by `Editor/SandboxSceneBuilder.cs`, both from shared pieces in `Editor/SceneBuildKit.cs`. Change the builder, not the scene, or the change is lost on rebuild.
- UI is built in code through `UIFactory` (uGUI, legacy `Text`). No prefabs or hand-built canvases yet.
- World taps go through `GameInput`; story scenes lock world input with `GameInput.Lock()`/`Unlock()`.
- Mobile performance: no per-frame allocations in `Update`, keep scenes small, respect the safe area.
- No premature systems: no config files, settings menus, telemetry, analytics, or full save system until asked. What persists today: the DecisionLog (decisions.json). Phone notes and photos last for the session.
- Prefer simple, readable code over frameworks. Small files, clear game-domain names.

## Verifying work
There is no Unity editor available to agents running in a sandbox. Before handing work back:
1. Syntax-check changed C# with the unity-project-workflow skill's `check_csharp.mjs` (or `mcs --parse` / `dotnet build` if available).
2. Compile-check changed Ink (see the ink skill's `check_ink.js`).
3. Tell the user which menu item to run and to paste any red Console errors.

## Editor menu items
| Menu | Does |
|---|---|
| EMP Escape > Build Test Slice Scene | Regenerates `Slice.unity` (Chapter 1 freeway slice) |
| EMP Escape > Build Action Sandbox | Regenerates `Sandbox.unity`: one station per interaction type (QTEs, dialogue, weapons, melee, shooting, death, end) |
| (note) | Each build puts its scene first in Build Settings, so the scene built last launches on the iPhone |
| EMP Escape > Reset Art Picks | Clears `SliceArtSet` and re-picks models from `Art/` by file name |
| EMP Escape > Reapply Animation Import Settings | Re-applies the clip import rules (loop, Loop Pose, root motion) to everything in `Art/Animations` |
| EMP Escape > Build Character Animator | Regenerates `Art/EMPCharacter.controller` from clips in `Art/Animations` |

## Keep these docs current (standing rule from the project owner)
When a new rule, convention, gotcha, or repeatable workflow comes up, update this file or add/extend a
skill in `.claude/skills/` in the same session. One skill per repeatable task, kebab-case folder,
`SKILL.md` with `name` and `description` frontmatter. Record what was learned, not session history.
